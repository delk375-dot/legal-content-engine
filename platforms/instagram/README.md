# Instagram

Папка для Instagram-каруселей, captions, stories і cover concepts.

Instagram має швидко показати конфлікт очима. Перший слайд - двері. Другий - ніж. Третій - пояснення, чому болить.

## Що зберігати

- carousel structures;
- captions;
- story hooks;
- cover image prompts;
- короткі цитати для слайдів;
- CTA для збережень і відповідей.

## Формула каруселі

1. Сильний cover hook.
2. Проблема.
3. Прихована механіка.
4. Приклад.
5. Практична формула.
6. Висновок.
7. CTA.

## Тон

Візуально чисто. Змістовно гостро. Без мотиваційного цукру.

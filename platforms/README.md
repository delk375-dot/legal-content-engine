# Platforms

Папка для адаптації кампаній під конкретні платформи.

Одна ідея не повинна звучати однаково всюди. TikTok хоче удар. YouTube Shorts хоче дугу. Facebook хоче думку. Instagram хоче структуру й візуальну напругу.

## Підпапки

- `tiktok/` - короткі відео, хуки, cover text, captions.
- `youtube/` - Shorts, community posts, thumbnail text.
- `facebook/` - довгі пости, короткі пости, дискусійні питання.
- `instagram/` - каруселі, captions, stories, visual prompts.

## Правило

Не копіюйте текст між платформами механічно. Перекладайте ідею мовою платформи. Інакше це не контент-система, а розсилка з різними шрифтами.

# Facebook

Папка для Facebook-адаптацій кампаній.

Facebook любить думку з хребтом. Тут можна розгорнути тезу, показати парадокс, додати соціальну механіку і поставити питання, після якого люди раптом мають що сказати.

## Що зберігати

- long posts;
- short posts;
- discussion questions;
- image concepts;
- comment prompts;
- versions for reposting.

## Формула поста

1. Заголовок або сильний перший рядок.
2. Напруга.
3. Парадокс.
4. Практичний висновок.
5. Короткий CTA.

## Правило

Не пишіть як пресслужба. Пишіть як людина, яка бачила систему зсередини і принесла ліхтарик.

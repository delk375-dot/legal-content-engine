# TikTok

Папка для TikTok-адаптацій кампаній.

TikTok не чекає, поки ви розігрієтесь. Якщо перші 2 секунди слабкі, аудиторія вже втекла до чужої драми.

## Що зберігати

- hooks;
- короткі сценарії;
- cover text;
- captions;
- image prompts для cover visuals;
- варіанти монтажної структури.

## Формула

1. Ударний хук.
2. Конфлікт.
3. Приклад.
4. Практична формула.
5. CTA.

## Тон

Коротко. Провокативно. Без лекції на кафедрі. Людина має відчути: "неприємно, але правда".

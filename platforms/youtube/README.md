# YouTube

Папка для YouTube Shorts, community posts і thumbnail ideas.

YouTube потребує трохи більше дуги. Тут працює не тільки удар, а й розслідування: що відбувається, чому це повторюється, кому це вигідно і що з цим робити.

## Що зберігати

- Shorts scripts;
- community posts;
- thumbnail text;
- image prompts для thumbnails;
- opening lines;
- closing CTA.

## Формула Shorts

1. Неприємне питання.
2. Соціальна механіка.
3. Приклад.
4. Практичний висновок.
5. CTA.

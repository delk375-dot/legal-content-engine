# Hooks

Папка для гачків уваги.

Хук - це не прикраса. Це двері. Якщо двері слабкі, аудиторія не заходить, навіть якщо всередині юридична мудрість, коучинг і маленький храм практичної користі.

## Як використовувати

Зберігайте тут:

- TikTok hooks;
- перші рядки Facebook-постів;
- opening lines для YouTube Shorts;
- фрази для першого слайда Instagram-каруселі;
- провокативні питання для кампаній.

## Формула

Сильний хук має:

- напругу;
- конфлікт;
- парадокс;
- психологічне впізнавання;
- обіцянку користі або неприємної правди.

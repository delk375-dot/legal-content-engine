# TikTok-хуки

Папка для коротких гачків уваги, перших фраз відео та ідей для швидкого входу в юридичну тему.

## Формат

- Проблема аудиторії.
- Сильна перша фраза.
- Обіцянка користі.
- Заклик додивитися або перейти до наступного кроку.

## Приклади напрямів

- Міфи про юридичні документи.
- Помилки підприємців у договорах.
- Права клієнта простими словами.
- Юридичні ситуації з повсякденного життя.

# Facebook-пости

Папка для довших постів, експертних пояснень, особистих спостережень і контенту для залучення аудиторії у Facebook.

## Типи контенту

- Експертний пост.
- Пост-історія.
- Пост із корисним чеклистом.
- Пост із запитанням до аудиторії.
- Пост із розбором типової помилки.

## Тон комунікації

Писати зрозуміло, людяно та впевнено. Юридичну складність пояснювати простими словами без втрати точності.

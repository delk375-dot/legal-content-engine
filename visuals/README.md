# Visuals

Папка для візуальних концепцій і image prompts.

Візуал має не просто бути красивим. Він має створювати напругу ще до того, як людина прочитала текст.

## Що зберігати

- cinematic image prompts;
- Netflix-style concepts;
- prompts для TikTok covers;
- prompts для Instagram carousel covers;
- prompts для Facebook-візуалів;
- YouTube thumbnail concepts.

## Візуальний стиль

- realistic;
- cinematic;
- dramatic lighting;
- psychological tension;
- intelligent atmosphere;
- social systems vibe;
- no text inside image;
- no logos.

## Правило

Спочатку напруга. Потім краса. Якщо навпаки - це вже реклама меблів, а не контент про владу, межі й людські рішення.

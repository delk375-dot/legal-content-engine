# Quotes

Папка для коротких гострих цитат.

Цитата - це концентрат кампанії. Один удар. Одна думка. Без пояснювального пуху.

## Як використовувати

Зберігайте тут:

- 10-15 цитат із кожної кампанії;
- фрази для сторіс;
- фрази для каруселей;
- вставки для відео;
- короткі постові тези.

## Формула

Хороша цитата має:

- напругу;
- парадокс;
- психологічне впізнавання;
- просту мову;
- відчуття, що людину щойно ввічливо викрили.

## Приклад

"Люди не ігнорують хаос. Вони просто не беруть його на баланс."

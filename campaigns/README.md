# Campaigns

Папка для повних контент-кампаній.

Кампанія - це коли одна ідея не вмирає одним постом, а розкладається на TikTok, YouTube Shorts, Facebook, Instagram, цитати, коментарі й візуали.

## Як працювати

1. Візьміть одну core idea з `ideas/`.
2. Відкрийте `campaign-template.md`.
3. Заповніть тезу, конфлікт, аудиторію і платформні блоки.
4. Рознесіть готові частини у відповідні папки, якщо потрібно.

## Що має бути в кампанії

- центральна думка;
- конфлікт;
- практичний висновок;
- платформи;
- візуальні промпти;
- цитати;
- коментарі для залучення.

## Тон

Провокативний, але корисний. Розумний, але не музейний. Іронічний, але не клоунський.

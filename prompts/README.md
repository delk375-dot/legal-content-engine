# Промпти

Папка для промптів, які допомагають генерувати, редагувати та адаптувати юридичний і коучинговий контент українською мовою.

## Категорії промптів

- Генерація TikTok-хуків.
- Написання Facebook-постів.
- Перетворення юридичного кейсу на історію.
- Адаптація складного тексту для широкої аудиторії.
- Створення коучингових запитань.

## Базовий шаблон

```text
Ти допомагаєш створювати україномовний юридичний контент.
Тема: [вставити тему]
Аудиторія: [описати аудиторію]
Формат: [TikTok / Facebook / історія / коучинговий пост]
Тон: зрозумілий, професійний, людяний
Завдання: створи чернетку контенту з чіткою структурою та практичним висновком.
```

# Legal Content Engine

Україномовна система для створення юридичного контенту, коротких відео, постів у Facebook, сторітелінгу та коучингових матеріалів.

## Структура

- `hooks/` - TikTok-хуки для коротких відео та Reels.
- `facebook/` - ідеї, чернетки та шаблони постів для Facebook.
- `legal/` - юридичний сторітелінг, кейси, пояснення та освітній контент.
- `coaching/` - коучингові матеріали, запитання, вправи та контент для довіри.
- `prompts/` - промпти для генерації, редагування та адаптації контенту.

## Мета

Зберігати контент-ідеї в одному місці, швидко перетворювати юридичну експертизу на зрозумілі дописи та будувати послідовну комунікацію з аудиторією.

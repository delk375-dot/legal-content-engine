# Legal Content Engine

Україномовна фабрика юридичного, коучингового та соціально-психологічного контенту.

Одна ідея тут не залишається просто ідеєю. Вона проходить через систему і стає кампанією: відео, постами, каруселями, цитатами, коментарями, візуалами та платформними адаптаціями.

## Принцип

Беремо одну сильну думку.

Знаходимо конфлікт.

Називаємо соціальну механіку.

Перетворюємо це на контент для TikTok, YouTube, Facebook, Instagram та візуальних форматів.

Без корпоративного туману. Без стерильної експертності. З ясністю, напругою і практичною користю.

## Основна структура

- `ideas/` - сирі ідеї, спостереження, тези, теми та конфлікти.
- `campaigns/` - повні мультиплатформні кампанії з однієї core idea.
- `visuals/` - промпти та концепції для обкладинок, каруселей і кінематографічних зображень.
- `hooks/` - гачки уваги для відео, постів і каруселей.
- `quotes/` - короткі гострі цитати для окремих постів, сторіс і вставок у відео.
- `comments/` - коментарі для залучення, дискусійні питання та відповіді аудиторії.
- `platforms/` - адаптації під конкретні платформи.

## Платформи

- `platforms/tiktok/` - короткі відео, хуки, cover text, captions.
- `platforms/youtube/` - Shorts, community posts, thumbnail ideas.
- `platforms/facebook/` - довгі пости, короткі пости, дискусійні формати.
- `platforms/instagram/` - каруселі, captions, stories, cover concepts.

## Головний шаблон

Використовуйте `campaigns/campaign-template.md`, щоб перетворити одну ідею на повний контент-пакет.

## Стиль

Провокативно. Розумно. Іронічно. Психологічно точно.

З поглядом на соціальні системи, владу, страх, межі, увагу, гроші й комунікацію.

Тон: суміш журналістського розслідування, Netflix-нарації, юридичної психології та коучингу.

# Ideas

Папка для сирих ідей.

Тут живуть спостереження, теми, конфлікти, фрази з консультацій, соціальні патерни та маленькі неприємні правди, з яких потім виростають кампанії.

## Що додавати

- одну core idea;
- тезу або парадокс;
- біль аудиторії;
- приклад із життя;
- юридичний або психологічний механізм;
- потенційний конфлікт.

## Формат ідеї

```text
Ідея:
Чому це болить аудиторії:
Який соціальний механізм тут видно:
Практичний висновок:
Можлива назва кампанії:
```

## Правило

Не поліруйте ідею занадто рано. Сирість тут дозволена. Стерильність - ні.

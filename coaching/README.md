# Коучинговий контент

Папка для матеріалів, які допомагають аудиторії думати ясніше, ухвалювати рішення та діяти впевненіше.

## Можливі матеріали

- Запитання для самоаналізу.
- Вправи для прийняття рішень.
- Контент про межі, відповідальність і вибір.
- Пости про страхи, сумніви та дії.
- Міні-сценарії для консультацій або ефірів.

## Стиль

Підтримувальний, спокійний і практичний. Без тиску, але з чітким фокусом на дію.

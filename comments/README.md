# Comments

Папка для коментарів, дискусійних питань і залучення аудиторії.

Коментар - це не хвостик після поста. Це другий акт. Там аудиторія або заходить у розмову, або мовчки йде далі жити зі своїми поганими повідомленнями.

## Що зберігати

- engagement comments;
- провокативні питання;
- відповіді на типові заперечення;
- коментарі для підняття дискусії;
- follow-up питання після публікації.

## Формула

Добрий коментар:

- легко відповісти;
- трохи зачіпає его;
- відкриває досвід аудиторії;
- не звучить як анкетування в банку.

## Приклад

"Яка фраза у повідомленнях вас дратує найбільше: 'уточнити', 'повернутися до питання' чи 'давайте якось обговоримо'?"
